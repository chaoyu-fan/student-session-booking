# 中小学生预约数据使用边界

- 最小字段：学生姓名、可选班级、预约开始与结束时间、咨询主题六选一和时段类型；老师端可设置临时占用时段。
- 主题选项限定为六类，不要收集自由文本咨询原因、心理测量、诊断、病史、咨询记录或紧急情况详情。主题可能属于敏感个人信息，仅老师后台可见并应设置合理的保留/删除规则。
- 任何学生不可搜索/查看其他学生预约；公开可见的只有空闲时间，确认页链接是随机令牌，应提醒学生勿随意转发。
- 无登录/验证码无法证明填写的身份真实；恶意抢号、冒名预约仍可能发生。可先限制范围发链接和设置访问码，正式使用需按学校评估进一步验证。
- 老师后台专用密码必须随机、独立、保存在服务器，不能公开；公网必须开启 HTTPS。
- 网站不是危机干预工具。页脚必须保留学校适用的紧急联系方式说明（上线前请老师确认）。
- 学生是未成年人，敏感场景需要学校许可、适用的监护与个人信息处理规则、访问权限约束、数据存储位置和保存/删除策略。
- 默认无第三方推送，减少隐私外泄面；服务器及备份仍需进行权限与加密保护。
- 建议由学校确定预约信息保留周期并实现自动清理；**V1 暂不含自动删除**，上线前需决定具体保留政策及实施方式。

- 紧急咨询09:50–10:10是预约档，不代表实时危机处置；发生即时危险时使用学校紧急求助/危机处置途径。
