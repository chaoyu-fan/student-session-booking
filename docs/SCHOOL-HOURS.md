# 学校作息时间（由老师提供，2026-10）

**此文件记录教师提供的实际节次时间**，不再使用网络模板推断。内容属于通用铃声时间，不包含个人学生信息或老师具体任课班级。

| 节次 | 起止时间 | 说明 |
|---|---|---|
| 第1节 | 08:00–08:45 | 正常上课，45分钟 |
| 第2节 | 09:00–09:45 | 正常上课，45分钟 |
| 课间操 | 09:45–10:15 | 全校活动，30分钟；工作日独立屏蔽 |
| 第3节 | 10:15–11:00 | 正常上课，45分钟 |
| 第4节 | 11:15–12:00 | 正常上课，45分钟 |
| 第5节 | 14:00–14:45 | 正常上课，45分钟 |
| 第6节 | 15:00–15:45 | 正常上课，45分钟 |
| 第7节 | 16:00–16:45 | 正常上课，45分钟 |
| 第8节 | 16:55–17:35 | **课后服务，40分钟，不属于正常教学节次** |

- 第1–7节课45分钟，正常课间15分钟；第2节课后为30分钟课间操。第7节后至第8节仅10分钟，第8节单独40分钟。
- 默认只屏蔽老师实际授课的时间段，课前课后不另加缓冲；课间操仅屏蔽09:45–10:15本身，不再额外叠加缓冲。
- **第8节课后服务仅在老师实际被排课时被占用**（来自本地私有课表），其他日期不自动屏蔽整节。是否开放给学生仍受预约基础窗口及校方许可限制。
- 50分钟会谈的单个时段不能放进15分钟普通课间；目前系统会根据实际时间与固定课程自动计算，无需手工凑时段。
- 当前 `MORNING_START/END`, `AFTERNOON_START/END` 仍来自服务器 `.env` 的对外预约窗口；**确认老师空档 ≠ 保证学生能离开自己的课**，须学校安排许可。
- 新安装默认预填本表时间，学生预约仍须导入真实任课课表后才可启用。
- 升级规则：旧版若仍使用未确认的示例八节钟点，自动替换成本表；若旧版已确认或管理员已自定义钟点，保持不变，老师须在后台核对并更新。旧版已启用站点的课间操默认暂不激活，防止悄悄改变已预约日程，老师应核对后显式启用。
